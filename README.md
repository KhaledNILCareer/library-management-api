# Library Management API

Backend RESTful API for managing library users, books, authors, and borrowing operations, with a simple Gemini-powered book summarization feature.

## Planned modules
- Authentication & Authorization
- Users / Roles
- Books
- Authors
- Borrowing & Returns
- Gemini AI Book Summarization
- Swagger / OpenAPI Documentation
- Testing

## Team workflow
- `main` is the stable branch.
- Create a branch for each Jira issue, e.g. `feature/LIB-12-user-login`.
- Open a Pull Request before merging into `main`.
- Do not commit secrets or `.env`.

## Setup
Project dependencies and runtime configuration will be added once the team confirms the Node.js stack and database choices.
